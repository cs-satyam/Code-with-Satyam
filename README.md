## How to Run

### Using IntelliJ IDEA

1. Open this folder in IntelliJ IDEA.
2. Select either `DSA Practice` or `Java_FullStack` as the project/module.
3. Open any Java file with a `main` method.
4. Run the file directly from the editor.

### Using Terminal

From the repository root, compile a Java file like this:

```bash
javac "DSA Practice/src/Stacks/validParentheses.java"
```

Then run it using the class name and classpath:

```bash
java -cp "DSA Practice/src" Stacks.validParentheses
```

For files inside `Java_FullStack`, use:

```bash
javac "Java_FullStack/src/Interface/launchInterface.java"
java -cp "Java_FullStack/src" Interface.launchInterface
```

Note: Package names and class names must match the Java file structure. If a file has no package declaration, run it from the folder where it is compiled.

## Getting started

Prerequisites
- Java Development Kit (JDK) 8 or later. For new projects it's recommended to use a modern LTS release (e.g., Java 17 or newer).
- Optional: Maven or Gradle if the project uses a build tool.

Cloning the repository

    git clone https://github.com/cs-satyam/Code-with-Satyam.git
    cd Code-with-Satyam

Building and running

If a specific project in this repository uses Maven:

    # build
    mvn clean package

    # run (example, replace with actual artifact name)
    java -jar target/your-artifact-name.jar

If a project uses Gradle (wrapper available):

    ./gradlew build
    ./gradlew run

For simple single-file or small projects without a build tool:

    # compile
    javac -d out src/path/to/YourClass.java

    # run
    java -cp out path.to.YourClass

Running tests

- Maven: mvn test
- Gradle: ./gradlew test
