## Getting started

### Prerequisites

- JDK 17 or later
- IntelliJ IDEA (recommended) or another Java IDE

### Run in IntelliJ IDEA

1. Open the repository in IntelliJ IDEA.
2. Open the project folder you want to explore.
3. Run a Java file that contains a `main` method.

### Run from the terminal

Compile and run a class using its source directory as the classpath. For example:

```powershell
javac "DSA Practice/src/Stacks/validParentheses.java"
java -cp "DSA Practice/src" Stacks.validParentheses
```

For packaged classes, use the fully qualified class name. Some solution files are intended for online judges and may not include a `main` method.

## Notes

- Source code lives in each project's `src` folder or problem-specific directory.
- `out/` directories contain IDE-generated compiled files.
- This is a learning and revision repository; implementations may use different styles as concepts evolve.
